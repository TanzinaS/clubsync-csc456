# Tests

Test plans, test cases, and automated tests for ClubSync.

**QA Lead:** Ayman
Developers are also expected to test their own work before opening a pull request.

## Folders

| Folder | Purpose |
|---|---|
| `frontend/` | Tests for UI pages and components |
| `backend/` | Tests for API endpoints and backend logic |

Testing tools will be chosen once the tech stack is decided.

## Manual Test Cases

Until automated tests exist, manual test cases can be written in Markdown using this format:

```text
Test ID:       TC-001
Feature:       Landing page navigation
Steps:         1. Open the landing page  2. Click "Events"
Expected:      Events feed page loads
Actual:
Status:        Pass / Fail
Tested by:
Date:
```

## Reporting Bugs

Report bugs as GitHub Issues using the **Bug Report** template.
