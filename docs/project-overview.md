# Project Overview

## Problem

CCNY club events are announced across many places — flyers, emails, social media, and word of mouth. Students easily miss events they would care about, and there is no single place to see them alongside their own schedule.

## Solution

ClubSync is a web application where students can:

1. Discover campus clubs.
2. Select clubs they are interested in.
3. See upcoming events from those clubs in a feed.
4. View events in a personalized calendar.

## Target Users

- **Primary:** CCNY students looking for club events.
- **Possible future:** club officers who post and manage events (not yet confirmed).
